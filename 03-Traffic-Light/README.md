Traffic Light Arduino Simulation

This project simulates a traffic light system using Arduino and SimulIDE.

Components

- Arduino
- Red LED
- Yellow LED
- Green LED
- Resistors

Traffic Light Sequence

1. Red LED – 15 seconds
2. Yellow LED – 1 second
3. Green LED – 10 seconds
4. Yellow LED – 1 second

The sequence repeats continuously using the "loop()" function.
